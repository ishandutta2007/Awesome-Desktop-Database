# Awesome-Desktop-Database

**Curated List of Commercial Tools & Open-Source GitHub Projects**
*Focused on No-Code Databases, Desktop Data Apps, Self-Hosted Alternatives & Form Builders*
**Last updated: October 2026**

This repository tracks notable **commercial platforms** and **open-source projects** for **Desktop Database** applications. These tools help teams and individuals build data-driven applications, manage records, and create internal tools without requiring deep database expertise.

**Examples** include Microsoft Access, FileMaker Pro, LibreOffice Base, Kexi, Airtable, Knack, Caspio, Quickbase, Claris Pro, and Ninox (the category leaders).

**Open-source emphasis**: The open-source desktop database ecosystem is **mature and production-proven**. **NocoDB** is the leading Airtable alternative with **50,000+ GitHub stars**, connecting to existing SQL databases and exposing them through a spreadsheet-like UI with Kanban, calendar, gallery, and form views . **Baserow** provides a polished no-code database workspace with a cleaner interface for non-technical users . **Kexi** offers a full-featured desktop database tool with built-in SQLite engine, PostgreSQL/MySQL connectivity, and a report designer . **LibreOffice Base** delivers a familiar desktop database front-end with support for dBASE, MySQL, and Oracle connections . This section documents these production-grade solutions.

## ⚠️ Disclaimer

- This is a **community-curated** list — not exhaustive and not an endorsement.
- Desktop database tools handle sensitive organizational data; ensure proper security configuration, access controls, and compliance with data protection regulations.
- **Open-source reality**: The open-source ecosystem for desktop databases is **mature and production-proven**. **NocoDB** leads as the Airtable alternative with **55,000+ stars**, connecting to existing SQL databases and exposing them through intuitive views . **Baserow** provides a polished interface for non-technical users . **Kexi** offers a full desktop database experience with SQLite, PostgreSQL, and MySQL connectivity . **LibreOffice Base** provides a familiar front-end with dBASE support and external database connections . However, **commercial platforms** (Microsoft Access, FileMaker Pro, Airtable) provide **polished user experiences, extensive template libraries, and managed infrastructure** that open-source alternatives may lack. The open-source path is **genuinely viable** for teams with technical capacity seeking full data sovereignty and cost control.
- **Licensing caveat**: **Microsoft Access Runtime is free** for end users running completed applications, but **no design capabilities** are available . **Airtable was acquired by Bending Spoons for $1.285B** in August 2026 — future pricing and roadmap changes are possible . Always evaluate long-term vendor stability before committing to a proprietary platform.
